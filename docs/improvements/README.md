# 개선 작업 이력

이 디렉터리는 특정 개선 pass의 spec과 implementation 기록을 보관합니다. 문서 이름에 `implementation`이나 round가 있어도 현재 승인, 완료, merge 또는 배포 상태를 보장하지 않습니다.

현재 구조와 동작은 실제 코드, `settings.gradle.kts`, [아키텍처](../architecture.md), [모듈 계약](../module-contracts.md)과 관련 live 계약에서 확인합니다. 실제 변경을 재개할 때는 [에이전트 워크플로](../agent-workflow.md)를 따릅니다.

대표 진입점:

- [Clean code 개선 spec](clean-code-improvements-spec.md)
- [Clean code 개선 round 2 spec](clean-code-improvements-round2-spec.md)
- [현재 문서 허브로 돌아가기](../README.md)

이 목록은 탐색 시작점일 뿐 exhaustive index가 아닙니다. 기존 report body는 현재 상태에 맞춰 재작성하지 않습니다.
