# Superpowers 설계·계획 이력

이 디렉터리는 작업 당시 작성한 spec, implementation plan과 검토 맥락을 보관합니다. 날짜가 최신이거나 파일명에 `approved`, `final`, `implementation`이 있어도 현재 승인, 완료, merge 또는 release 상태를 뜻하지 않습니다.

현재 사실은 실제 코드, `settings.gradle.kts`, Gradle task와 [현재 문서 허브](../README.md)의 live 계약에서 확인합니다. 구조는 [아키텍처](../architecture.md), 실행 순서는 [에이전트 워크플로](../agent-workflow.md), 검증 선택은 [검증 매트릭스](../verification-matrix.md)가 소유합니다.
