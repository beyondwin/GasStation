# Release Notes — v1.1.1 (2026-05-13)

이 문서는 v1.1.1에서 실제로 적용된 변경을 기록합니다.

## 사용자 관점 변경

사용자 플로우와 화면 동작은 v1.1.0과 같습니다. 이번 릴리즈는 가까운 주유소 비교, stale cache fallback, watchlist 비교, 외부 지도 handoff 흐름을 유지하면서 내부 경계와 릴리스 검증 체계를 정리한 patch 릴리즈입니다.

## 개발자 품질 기반

### Clean Architecture 경계 정리

- `CrashReporter` 계약을 `domain:station`에서 `core:observability`로 이동했습니다.
- `core:location`은 더 이상 station domain을 참조하지 않고, 위치 인프라와 station 이벤트 계약이 분리됩니다.
- 앱은 기존처럼 demo는 `NoOpCrashReporter`, prod는 `LogcatCrashReporter`를 Hilt로 바인딩합니다.

### 주소 라벨 정규화 단일화

- 행정동 중심 주소 라벨 정규화 규칙을 `domain:location/AddressLabelNormalizer.kt`로 올렸습니다.
- `core:location`은 Android `Address` 후보를 domain 정규화 규칙에 통과시키고, station list는 중복 주소 파싱을 소유하지 않습니다.

### 값 객체와 data 조립 책임 정리

- 좌표 거리 계산은 `Coordinates.distanceTo`, 브랜드 코드 fallback은 `Brand.fromCode`로 중앙화했습니다.
- `DefaultStationRepository`에서 검색 결과와 watchlist 요약 조립을 `StationSearchResultAssembler.kt`, `WatchlistSummaryAssembler.kt`로 분리했습니다.
- repository test double은 `RepositoryDoubles.kt`, station-list ViewModel fixture는 `StationListViewModelTestFixtures.kt`로 옮겨 테스트 본문을 줄였습니다.

### Station-list UI 파일 분리

- `StationListScreen.kt`는 screen scaffold와 refresh rail 중심으로 축소했습니다.
- 카드, 상태 화면, query context, body state는 각각 `StationListCards.kt`, `StationListStates.kt`, `StationListQuerySummary.kt`, `StationListBodyState.kt`가 소유합니다.
- 가격 우선 정보 위계, 브랜드 아이콘 중심 목록 카드, watch semantics, test tag 계약은 유지됩니다.

### CI scope 조정

- PR에서는 static analysis, unit tests, screenshot tests, demo/prod debug assemble, benchmark assemble을 확인합니다.
- `prodRelease` assemble과 coverage는 `main` 또는 `v*` tag push에서 실행합니다.
- 이 조정은 PR 피드백 시간을 줄이면서 release 성격의 검증은 main/tag 경로에서 유지하기 위한 변경입니다.

## 마이그레이션 안내

Room schema, DataStore 포맷, demo seed 자산, Opinet API key 흐름은 변경하지 않았습니다. 사용자 데이터 마이그레이션이 필요하지 않습니다.

## 문서

- README의 현재 버전, 릴리스 인덱스, 모듈 그래프를 v1.1.1 기준으로 갱신했습니다.
- `docs/architecture.md`, `docs/module-contracts.md`, `docs/state-model.md`, `docs/test-strategy.md`, `docs/verification-matrix.md`를 `core:observability`, 주소 정규화, station-list/data 분리 구조에 맞췄습니다.
- `AGENTS.md`와 `docs/agent-workflow.md`에 observability 경계와 주소 라벨 소유권을 반영했습니다.
