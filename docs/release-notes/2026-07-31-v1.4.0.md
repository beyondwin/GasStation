# Release Notes - v1.4.0 (2026-07-31)

이 문서는 v1.4.0에서 실제로 적용된 변경을 기록합니다.

## 요약

v1.4.0은 앱을 처음 발견하고 여는 순간의 GasStation 정체성을 다듬은 기능 릴리스입니다. Launcher, themed icon, AndroidX splash가 같은 refined droplet을 사용하고, 첫 frame은 reduced-motion을 존중하는 짧은 signal pulse로 본문에 연결됩니다. 릴리스 운영도 tag CI 성공 뒤 GitHub Release와 APK checksum이 자동 게시되도록 닫았습니다.

## 사용자 영향

- adaptive/legacy launcher, themed monochrome, AndroidX splash가 같은 검정 물방울 silhouette를 사용합니다. mask가 다른 launcher에서도 중심과 여백을 유지하도록 density별 자산을 다시 만들었습니다.
- 정적 splash foreground는 권한, 위치, demo seed, 설정, 네트워크를 기다리지 않습니다. 앱 첫 frame이 준비되면 180ms fade/scale exit로 전환하고, 시스템 animator scale이 0이면 custom exit를 즉시 제거합니다.
- API 31+에서 고정 settle delay를 제거해 splash를 위한 불필요한 startup 대기를 없앴습니다.
- root navigation inset을 한 번만 적용해 관심 화면을 포함한 edge-to-edge destination에서 하단 여백이 중복되지 않습니다.

## 개발자 영향

- `SplashExitAnimator`, theme/resource contract, source provenance 테스트가 static foreground, 180ms exit, animations-off cleanup, one-shot removal을 보호합니다.
- refined droplet의 승인 SVG/PNG와 icon audit를 `docs/design-assets/app-icon/`에 보관하고, API 30/API 37 launcher·splash·themed icon evidence 경로를 검증 매트릭스에 기록했습니다.
- benchmark helper는 현재 Compose test tag를 사용해 watchlist journey와 앱 selector가 어긋나지 않게 했습니다.
- GitHub Actions `release-publish`는 `agent-contracts`, `static-analysis`, `unit-tests`, `screenshot-tests`, `assemble`, `release-assemble`, `coverage`가 모두 성공한 tag에서만 실행됩니다.
- tag release는 installable demo debug APK, 서명되지 않은 minified prod release APK, 두 파일의 `SHA256SUMS.txt`를 게시합니다. `contents: write`는 release job에만 부여하고 저장소 기본 workflow 권한은 read-only로 유지합니다.
- `SHA256SUMS.txt`는 다운로드 위치와 무관한 APK 파일명만 기록해 세 자산을 같은 디렉터리에 받은 뒤 표준 `sha256sum -c`로 검증할 수 있습니다.
- `scripts/agent/check-contracts.sh --ci`와 fixture test가 release job의 tag 조건, 선행 job, 권한, release note, artifact, GitHub CLI 게시 계약을 보호합니다.

## 배포와 호환성

- Room schema, DataStore 포맷, demo seed, Opinet request contract는 바뀌지 않아 사용자 데이터 migration이 필요하지 않습니다.
- `demo`와 `prod`의 사용자 흐름, 위치 권한 gate, 선택 유종 watchlist, 외부 지도 handoff는 v1.3.0 계약을 유지합니다.
- GitHub Release의 demo debug APK는 설치 가능한 검증용 산출물입니다. prod release APK는 R8 minification 결과를 확인하는 unsigned 산출물이며 Play Store 배포용 서명본이 아닙니다.
- signed prod APK/AAB, Play Store 업로드, live Opinet 조회는 저장소 자동화 범위 밖입니다. 서명 keystore와 배포 credential은 저장소에 두지 않습니다.
