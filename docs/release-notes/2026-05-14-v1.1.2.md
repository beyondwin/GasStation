# Release Notes — v1.1.2 (2026-05-14)

이 문서는 v1.1.2에서 실제로 적용된 변경을 기록합니다.

## 사용자 관점 변경

사용자 플로우와 화면 동작은 v1.1.1과 같습니다. 이번 릴리즈는 가까운 주유소 비교, stale cache fallback, watchlist 비교, 외부 지도 handoff 흐름을 유지하면서 build/test 경로와 CI 안정성을 정리한 patch 릴리즈입니다.

## 개발자 품질 기반

### Build/test fast path 정리

- Gradle configuration cache, build cache, parallel execution을 기본 활성화했습니다.
- Roborazzi screenshot class는 일반 unit test task에서 제외하고, screenshot 회귀는 `verifyRoborazziDebug`가 소유하도록 분리했습니다.
- Compose compiler report와 metric은 기본 생성하지 않고, `-Pgasstation.composeCompilerReports=true`를 전달할 때만 생성합니다.
- 기본 lint는 production source 중심으로 실행하고, test source lint는 `-Pgasstation.lintTestSources=true`로 명시할 때만 확장합니다.

### CI 메모리 안정화

- GitHub Actions `assemble` job은 demo debug, prod debug, benchmark assemble을 별도 Gradle 호출로 실행합니다.
- 이 조정은 `org.gradle.parallel=true` 상태에서 두 app flavor와 benchmark assemble이 같은 daemon 메모리 피크에 몰려 `:app:hiltJavaCompileProdDebug`가 `Java heap space`로 실패하던 문제를 방지합니다.
- `main` push 기준 Android CI run `25838751686`에서 변경 후 전체 workflow가 통과했습니다.

### 테스트 소유권 정리

- app resource smoke test는 demo unit test source set으로 옮겨 중복 app resource test 실행을 줄였습니다.
- station route의 availability 관찰 정책은 `StationListRoutePolicy`와 JVM unit test로 분리해 빠른 테스트 경로에서 보호합니다.
- 예제 Android/unit test 파일은 실제 제품 계약을 검증하지 않으므로 제거했습니다.

## 마이그레이션 안내

Room schema, DataStore 포맷, demo seed 자산, Opinet API key 흐름은 변경하지 않았습니다. 사용자 데이터 마이그레이션이 필요하지 않습니다.

## 문서

- README의 현재 버전과 릴리즈 인덱스를 v1.1.2 기준으로 갱신했습니다.
- `CHANGELOG.md`에 v1.1.2 요약을 추가했습니다.
- `docs/verification-matrix.md`에 CI assemble job의 별도 Gradle 호출 기준을 반영했습니다.
- build/test 속도 개선 설계와 구현 이력은 `docs/superpowers/specs/2026-05-14-build-test-speed-implementation.md`와 `docs/superpowers/plans/2026-05-14-build-test-speed-improvements.md`에 보관합니다.
