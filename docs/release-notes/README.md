# Release note 이력

이 디렉터리는 버전별 사용자 영향, 개발자 영향과 당시 검증 결과를 보관합니다. 날짜나 버전 파일명이 현재 tag, GitHub Release, 배포 완료 또는 설치 가능한 signed artifact를 자동으로 증명하지 않습니다.

현재 앱 버전은 `app/build.gradle.kts`, 변경 요약은 [`CHANGELOG.md`](../../CHANGELOG.md), 발행 절차와 산출물 경계는 [배포](../deployment.md)를 우선합니다. 실제 remote release 상태는 별도 조회 없이는 현재 사실로 주장하지 않습니다.

대표 진입점:

- [v1.4.0 release note](2026-07-31-v1.4.0.md)
- [v1.3.0 release note](2026-07-25-v1.3.0.md)
- [현재 문서 허브로 돌아가기](../README.md)

이 목록은 최신 몇 개의 탐색 시작점만 제공하며 exhaustive version index가 아닙니다. 과거 release note body는 보존합니다.
