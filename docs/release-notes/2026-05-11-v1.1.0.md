# Release Notes — v1.1.0 (2026-05-11)

이 문서는 v1.1.0에서 실제로 적용된 변경을 기록합니다.

## 사용자 관점 변경

### i18n: 영어 locale 지원

시스템 locale이 영어(`en`)일 때 주요 UI 문자열이 올바르게 표시됩니다. `StringResource` 래퍼를 도입해 `feature`/`core:designsystem` 레이어가 하드코딩된 한국어 리터럴을 직접 사용하지 않게 됩니다.

### Baseline Profile (deferred)

시작 속도 최적화를 위한 Baseline Profile 수집은 AGP 9.1.1과 `androidx.baselineprofile` 1.4.1 인프라 호환성 문제로 이번 릴리즈에서 제외됩니다. README의 startup metric 표는 수집 완료 후 갱신됩니다.

## 개발자 품질 기반

### 화면 회귀 테스트 (Roborazzi)

9개 골든 스크린샷 추가:

- `core:designsystem` — 5개 (primary button variants, metric card, row primitive 등)
- `feature:station-list` — 4개 (Loading, Empty, Error, 목록 렌더링 상태)

CI `screenshot-tests` job이 `verifyRoborazziDebug`로 회귀를 자동 검사합니다. 실패 시 diff artifact가 업로드됩니다.

### Compose 품질

- Compose stability metrics: `compose-reports` / `compose-metrics` 출력 4개 모듈 설정 완료.
- Baseline profile: deferred (AGP 9.1.1 호환성 대기).
- Startup metric: README placeholder 표 — 수집 완료 후 실제 수치로 갱신 예정.

### 코드 품질 도구

- Spotless + ktlint: convention plugin을 통해 전 모듈에 강제 적용.
- Lint: `abortOnError = true`, `checkDependencies = true` 기준.
- Kover 0.9.1: `koverXmlReport` / `koverHtmlReport` 전 모듈 집계, Hilt/Compose 생성 코드 제외.
- Codecov 업로드는 `CODECOV_TOKEN`이 설정된 경우에만 실행되도록 env gate로 분리해, secret이 없는 저장소에서도 workflow 파일 파싱이 실패하지 않습니다.
- 로컬 `.orchestrator` 실행 산출물은 repository history에 남지 않도록 추적 대상에서 제거하고 `.gitignore`에 추가했습니다.
- CrashReporter 추상화: `app` 모듈에 인터페이스 도입.

### CI 개선

GitHub Actions workflow를 단일 job에서 5개로 분리:

| Job | 역할 |
| --- | --- |
| `static-analysis` | spotlessCheck + lint |
| `unit-tests` | 전 모듈 단위 테스트 |
| `screenshot-tests` | verifyRoborazziDebug + diff artifact |
| `assemble` | demo/prod debug + prod release |
| `coverage` | koverXmlReport (unit-tests 완료 후) |

동시 실행으로 전체 CI 시간 단축, `cancel-in-progress: true`로 불필요한 실행 제거.

## 마이그레이션 안내

변경 없음. Room schema, API key 흐름, demo seed 자산은 이전과 동일합니다. 사용자 데이터 마이그레이션이 필요하지 않습니다.
