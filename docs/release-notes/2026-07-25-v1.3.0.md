# Release Notes - v1.3.0 (2026-07-25)

이 문서는 v1.3.0에서 실제로 적용된 변경을 기록합니다.

## 요약

v1.3.0은 가격 비교 속도를 높이는 Urban Signal UI와 화면 간 상태 무결성을 함께 완성한 기능 릴리스입니다. 주변·관심·설정 화면은 같은 yellow/black/white 정체성 안에서 더 많은 비교 정보를 빠르게 보여 주며, 설정·위치 권한·선택 유종·외부 지도 provider는 저장된 값과 실제 동작이 끝까지 일치하도록 정리했습니다. Android toolchain, deterministic demo, 저장소 작업 계약, GitHub Actions도 같은 릴리스 경로에서 검증됩니다.

## 사용자 영향

- 주변 화면은 32sp 가격을 첫 번째 읽기 대상으로 유지하면서 flat station row, 최저가·검색 건수·평균가·절약액 요약, anchored filter menu, 명시적인 가격 이력 상태를 제공합니다.
- 반경·유종·브랜드·정렬 filter는 40dp 검정 surface와 14dp 모서리로 가볍게 보이지만, 실제 터치 영역은 최소 48dp이고 200% 글꼴과 320dp 화면에서도 잘리지 않습니다.
- 관심 화면은 최대 5개 저장 항목을 고밀도로 비교하고 설정의 선택 유종을 모든 가격·변동 계산에 적용합니다. 선택 유종 가격이 없어도 저장 항목은 사라지지 않고 가격 없음으로 표시됩니다.
- 설정은 overview/detail 구조를 사용하며, 첫 DataStore emission 전에는 임의의 기본 선택을 보여 주지 않습니다. 선택 저장이 성공한 뒤에만 이전 화면으로 돌아가므로 주변·관심 화면과 같은 committed 값을 사용합니다.
- `demo`도 `prod`와 같은 위치 권한 흐름을 따릅니다. 권한을 허용하기 전에는 고정 좌표나 기존 좌표로 목록을 열지 않고, 권한 요청과 앱 설정 복구는 사용자 action으로만 시작합니다.
- TMAP·카카오맵·네이버 지도 설정은 표시 이름, 저장 identity, Android package, route URI가 일치합니다. 설치되지 않은 provider는 Play Store로 안내하고 모든 handoff가 실패하면 앱 안에서 feedback을 표시합니다.
- icon-only bottom navigation은 `주변`, `관심`, `설정`의 접근성 의미와 tab별 state/scroll 복원을 유지합니다.

## 개발자 영향

- `StationSearchResult`는 `hasCachedSnapshot`을 명시적으로 전달받아 성공한 빈 조회와 cache 부재를 구분합니다. flavor별 remote source 선택은 `FlavorAwareStationRemoteDataSource`가 담당해 repository가 flavor 정책을 소유하지 않습니다.
- watchlist domain 경계는 `WatchlistQuery(origin, fuelType)`를 사용하고, 선택 유종 가격이 없는 저장 항목을 nullable price로 표현합니다. 제거는 명시적 `RemoveWatchedStationUseCase`를 통합니다.
- `MapProvider.KAKAO_MAP`이 현재 domain/storage identity입니다. `data:settings`는 legacy `KAKAO_NAVI`만 읽기 migration하고 새 쓰기는 현재 이름을 저장합니다.
- Gradle 9.6.1, AGP 9.3.0, Kotlin 2.4.10, Compose BOM 2026.06.01, compile SDK 37, target SDK 36과 최신 안정 AndroidX/빌드·테스트 의존성을 사용합니다. Gradle daemon toolchain은 Java 21에 고정합니다.
- Compose 테스트는 v2 테스트 환경 API를 사용하고 `verifyNoDeprecatedComposeTestApis`, `verifyCiRobolectricRuntime`, demo instrumentation compile을 CI가 보호합니다.
- coverage는 JaCoCo 0.8.15 기반 `coverageXmlReport`로 통합되며 Kover와 ben-manes versions의 Gradle 10 비호환 실행 경로는 제거했습니다. dependency freshness는 Dependabot이 매주 확인합니다.
- `scripts/agent/preflight.sh`, `scripts/agent/check-contracts.sh`, `scripts/agent/verify.sh`가 로컬 작업과 CI의 공통 계약입니다. linked worktree bootstrap과 portable hook도 같은 경계를 따릅니다.
- `tools:demo-seed:verifyDemoSeedAsset`은 체크인된 seed의 15개 query matrix, origin/version, 가격 히스토리, RTO/ETC portfolio station을 키와 네트워크 없이 검증합니다.

## 문서와 검증

- `README.md`, `docs/architecture.md`, `docs/state-model.md`, `docs/offline-strategy.md`, `docs/module-contracts.md`가 Urban Signal 화면 구조와 설정·권한·watchlist·외부 지도 런타임 경계를 설명합니다.
- `docs/test-strategy.md`와 `docs/verification-matrix.md`가 host, screenshot, connected demo, release, coverage 검증 경로와 각 증거의 한계를 구분합니다.
- `docs/agent-workflow.md`, `AGENTS.md`, module별 `AGENTS.md`, `CONTRIBUTING.md`가 저장소 작업자의 preflight와 검증 진입점을 설명합니다.
- `docs/deployment.md`는 release commit의 `main` CI 성공을 확인한 뒤 같은 SHA에 tag를 발행하도록 순서를 고정합니다.
- 물리 기기 성능 수치는 새로 수집하지 않았습니다. `docs/performance.md`의 Samsung Galaxy S20+ 5G 측정값과 baseline profile 제약이 최신 committed evidence입니다.
- live Opinet 조회, OEM별 permission controller UI, 설치된 외부 지도 앱의 최종 목적지 화면, 공개 서명·Play Store 업로드는 이번 저장소 자동 검증의 범위가 아닙니다.
