# Release Notes - v1.5.0 (2026-08-29)

이 문서는 v1.5.0에서 실제로 적용된 변경을 기록합니다.

## 요약

v1.5.0은 화면 정체성을 바꾸지 않고, 가격·위치·관심 저장이 동시성 아래에서도 최신 사용자 의도를 지키도록 닫은 품질 릴리스입니다. 문서 허브와 온보딩 경로를 짧게 다시 묶고, CI는 unsigned prod APK 재현과 차단형 품질 게이트를 공식 경로로 고정합니다.

제품 UI, Urban Signal 색, refined droplet launcher/splash는 v1.4.0 계약을 유지합니다.

## 사용자 영향

- 주변 목록의 신선도는 DB가 바뀌지 않아도 시간이 지나면 다시 계산됩니다. 오래된 가격을 계속 최신처럼 보여주지 않습니다.
- 같은 조건으로 연속 새로고침하면 나중에 시작한 결과가 이깁니다. 늦게 도착한 이전 요청이 최신 가격을 덮어쓰지 않습니다.
- 위치 권한을 바꾸는 동안 이전 좌표가 뒤늦게 목록에 적용되지 않습니다.
- 관심 저장/해제는 마지막 탭만 반영합니다. 먼저 시작한 변경이 나중에 끝나도 화면과 기록을 되돌리지 않습니다.

## 개발자 영향

- station 데이터는 최신 refresh 의도, 시간 기반 freshness, atomic bucket snapshot, typed transport/retry, exported Room schema를 함께 검증합니다.
- 주변 목록 상태는 위치·관찰·refresh·command·순수 projection으로 나뉘고, ViewModel은 조합만 담당합니다.
- CI는 production/test lint, coverage ratchet, public ABI, sealed mutation, unsigned prod 재현 receipt를 차단형으로 돌립니다. `v*` tag는 이 job이 모두 성공한 뒤에만 GitHub Release를 게시합니다.
- 문서 허브, catalog, 온보딩 4경로(`시작하기` · `아키텍처 둘러보기` · `변경 플레이북` · `검증과 전달`)가 현재 계약의 입구입니다.
- PreToolUse hook은 Claude/Codex `tool_input`과 Grok `toolInput`을 같은 명령 정책으로 검사합니다.
- Gradle dependency verification metadata는 운영하지 않습니다. 호환성은 configuration-cache 재사용과 CI graph/lint/test가 담당합니다.
- GitHub Ubuntu 24.04는 검토된 `ImageVersion=20260816.277.1`을 기본 pin으로 두고, 후속 `20260823.283.1`은 recapture 없이 허용합니다.

## 배포와 호환성

- Room schema, DataStore 포맷, demo seed, Opinet request contract는 사용자 데이터 재설치를 요구하지 않습니다.
- `demo`와 `prod`의 사용자 흐름, 위치 권한 gate, 선택 유종 watchlist, 외부 지도 handoff는 v1.4.0 계약을 유지합니다.
- GitHub Release의 demo debug APK는 설치 가능한 검증용 산출물입니다. prod release APK는 unsigned이며 Play Store 서명본이 아닙니다.
