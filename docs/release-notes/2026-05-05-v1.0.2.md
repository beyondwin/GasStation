# GasStation 1.0.2 릴리즈 노트

릴리즈 날짜: 2026-05-05

이 릴리즈는 deep analysis에서 즉시 필요하다고 판정한 네 가지 항목을 반영한 패치 릴리즈입니다. 사용자 플로우는 유지하면서 dependency 선언, CI 검증 범위, 테스트 인프라, watchlist semantics/test selector 계약을 정리했습니다.

## 무엇이 바뀌었나

### Dependency 관리

- `core:network`의 `proj4j` 의존성을 Gradle version catalog로 이동했습니다.
- KATEC 좌표 변환 의존성도 다른 외부 라이브러리처럼 `gradle/libs.versions.toml`에서 추적됩니다.

### CI와 검증

- GitHub Actions `Verification Matrix`가 `docs/verification-matrix.md`의 머지 전 권장 회귀 세트를 기준으로 동작하도록 맞췄습니다.
- CI는 `:domain:location:test`, `:app:testProdDebugUnitTest`, `:tools:demo-seed:test`를 포함합니다.
- aggregate `:app:assembleDebug`와 release assemble은 기본 matrix에서 제외했습니다. release assemble은 R8/minify 회귀를 모든 PR에서 잡기로 결정할 때 별도로 승격합니다.

### 테스트 인프라

- `feature:station-list`의 `StationListViewModelTest`가 `MainDispatcherRule`을 사용해 `Dispatchers.Main` 설정을 중앙화합니다.
- 테스트별 dispatcher setup 반복을 줄이고, `Dispatchers.resetMain()` 정리 계약을 한 곳에서 관리합니다.

### Watchlist semantics

- watchlist card와 distance metric selector를 ASCII `testTag`로 분리했습니다.
- 한글 접근성 문구는 `contentDescription`으로 유지해 스크린 리더 계약을 보존합니다.

### 문서

- README, CHANGELOG, 테스트 전략, 검증 매트릭스, 작업 절차, 프로젝트 읽기 가이드, deep analysis report, improvement backlog를 실제 구현 상태에 맞췄습니다.
- 조건부 backlog는 release assemble CI, `values-night-v31`, Gradle parallel/build cache, dark semantic migration, backend proxy로 남겨 두었습니다.

## 아직 실행하지 않은 외부 단계

- 기기 기반 `connectedDemoDebugAndroidTest`와 `connectedDebugAndroidTest`는 연결된 Android device/emulator가 있을 때 실행합니다.
- release assemble CI는 이번 릴리즈에서 기본 matrix로 승격하지 않았습니다.
- backend proxy, key restriction, quota monitoring은 공개 배포나 quota 보호 요구가 생길 때 설계합니다.
