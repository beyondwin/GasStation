# Compose compiler metrics 이력

이 디렉터리는 특정 시점에 수집한 Compose compiler stability·restartability 요약을 보관합니다. 파일 존재나 이름은 현재 최적화 승인, 문제 해결 또는 성능 완료를 뜻하지 않습니다.

현재 UI 구조는 실제 Compose source, [아키텍처](../architecture.md), [테스트 전략](../test-strategy.md)을 우선합니다. physical-device 사용자 성능은 이 metrics가 아니라 [성능 문서](../performance.md)의 benchmark evidence가 소유합니다.

대표 진입점:

- [design system metrics](core-designsystem.md)
- [station-list metrics](feature-station-list.md)
- [현재 문서 허브로 돌아가기](../README.md)

이 README는 exhaustive index가 아니며 과거 compiler report를 현재 HEAD의 측정값으로 승격하지 않습니다.
